# Құлаған мысалдар

Сыныптар арасындағы ауызша есеп жарысы. Оқушылар үзілісте таблодағы QR-кодты телефонмен сканерлеп,
атын және сыныбын жазады да, ойнайды. Мысалдар экранда жоғарыдан құлайды, оларды сызғышқа тигенше
шешу керек. Ойыншының 3 «боры» (өмірі) бар, қатарынан дұрыс жауап берсе комбо ×2/×3 болады, ал алтын мысал экранды тазалайды.
Әр 25 секунд сайын деңгей көтеріліп, мысалдар қиындай түседі.

Сынып ұпайы — оқушыларының 10 үздік нәтижесінің қосындысы. Сондықтан көп оқушысы бар сынып емес,
мықты ойыншысы көп сынып жеңеді.

## Беттер
| Мекенжай | Кімге арналған |
|---|---|
| `/screen` | Фойедегі проекторға немесе теледидарға арналған табло: QR-код, сыныптар жарысы, үздік ойыншылар (өзі жаңарады) |
| `/` | Оқушының телефонындағы ойын (QR осы бетке апарады) |
| `/admin` | Мұғалімге: әдепсіз атты не нәтижені өшіру, кестені тазалау (PIN арқылы) |

## 1-нұсқа. Мектеп компьютері + мектептің Wi-Fi желісі
Node.js 18+ керек.
```
npm install
ADMIN_PIN=7391 npm start
```
Консольде мекенжайлар шығады. Проекторға қосылған компьютерде `/screen` бетін ашыңыз.
Оқушылардың телефондары сол Wi-Fi желісіне қосылған болуы керек. QR-код компьютердің желідегі мекенжайын өзі қояды.

Windows (PowerShell): `$env:ADMIN_PIN="7391"; npm start`

## 2-нұсқа. Интернетте (оқушылар мобильді интернетпен кіреді, ойыншы саны шектелмейді)
Тегін: **Render** (сайт) + **Neon** (нәтижелер базасы). Қадамдар `ИНСТРУКЦИЯ.md` файлында жазылған.
Қысқаша: файлдарды GitHub-қа жүктеу → Render-де **New → Blueprint** → `ADMIN_PIN` және `DATABASE_URL` (Neon-нан) енгізу.
QR-код сайттың мекенжайын өзі қояды.

## Алдаудан қорғау
Сервер ойынның нақты ұзақтығын, шешілген мысалдар санын және ұпай мөлшерін тексеріп, күдікті нәтижені қабылдамайды.
