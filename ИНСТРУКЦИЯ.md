# Как выложить «Құлаған мысалдар» в интернет

После этого ученики заходят по QR со своим **мобильным интернетом**: точка доступа не нужна,
количество игроков не ограничено. Всё бесплатно, банковская карта не нужна.

Понадобятся три бесплатных аккаунта (удобнее всего входить через Google):
- **Neon** хранит результаты, чтобы они не пропадали;
- **GitHub** хранит файлы игры;
- **Render** запускает игру и даёт ей адрес в интернете.

Займёт примерно 15 минут, делается один раз.

---

## Шаг 1. База данных Neon (результаты)

1. Откройте **neon.tech** → **Sign up** → войдите через Google.
2. Создайте проект: имя любое, например `mysaldar`, регион — ближайший (например, Frankfurt).
3. На странице проекта нажмите **Connect** и скопируйте строку подключения.
   Она начинается с `postgresql://` и содержит пароль, поэтому никому её не показывайте.
4. Сохраните её в заметках, она понадобится в шаге 3.

## Шаг 2. Файлы игры на GitHub

1. Откройте **github.com** → зарегистрируйтесь → нажмите **New repository** (зелёная кнопка или «+» вверху).
2. Имя: `qulagan-mysaldar`. Можно выбрать **Private**. Нажмите **Create repository**.
3. На открывшейся странице нажмите ссылку **uploading an existing file**.
4. Распакуйте архив и перетащите в окно браузера **всё содержимое папки**:
   `server.js`, `package.json`, `package-lock.json`, `render.yaml`, `README.md`, `ИНСТРУКЦИЯ.md` и папку `public`.
   Важно: файл `render.yaml` должен лежать сразу в корне, а не внутри другой папки.
5. Нажмите **Commit changes**.

## Шаг 3. Запуск на Render

1. Откройте **render.com** → **Get Started** → войдите **через GitHub** и разрешите Render доступ к репозиторию `qulagan-mysaldar`.
2. Нажмите **New** → **Blueprint** и выберите репозиторий `qulagan-mysaldar`.
   Render сам прочитает настройки из `render.yaml` и попросит два значения:
   - `ADMIN_PIN` — придумайте PIN учителя, например `7391`;
   - `DATABASE_URL` — вставьте строку из шага 1.
3. Нажмите **Apply** (или **Deploy**). Через 2–3 минуты в логах появится строка `Құлаған мысалдар іске қосылды!`.
4. Вверху страницы сервиса будет адрес вида `https://qulagan-mysaldar-xxxx.onrender.com`. Это адрес вашей игры.

## Шаг 4. На перемене

- На ноутбуке с проектором откройте **`https://…onrender.com/screen`**. В QR-коде уже будет правильный адрес сайта.
- Открывайте табло **за 2–3 минуты до звонка**: на бесплатном тарифе сервер «засыпает», если сайтом
  15 минут никто не пользуется, и просыпается до минуты. Пока табло открыто, сервер не засыпает.
- Ученики сканируют QR и играют через свой мобильный интернет.
- Страница учителя: **`https://…onrender.com/admin`** с вашим PIN. Там можно удалить неприличное имя или очистить таблицу.

---

## Если что-то пошло не так

| Что видно | Что сделать |
|---|---|
| В логах Render: `Нәтижелерді жүктеу мүмкін болмады` | Неверная строка `DATABASE_URL`. Render → ваш сервис → **Environment** → вставьте строку из Neon заново → **Save**. |
| Сайт долго открывается | Сервер просыпается, подождите до минуты. |
| На `/admin` пишет `ADMIN_PIN орнатылмаған` | Добавьте `ADMIN_PIN` в Render → **Environment**. |
| Хочу изменить игру | Загрузите новые файлы в тот же репозиторий на GitHub. Render перезапустит игру сам, результаты сохранятся. |

Бесплатного места в Neon (0,5 ГБ) хватит на миллионы результатов.

Игра по-прежнему работает и без интернета, на школьном компьютере в общей сети Wi-Fi: `npm install`, затем `npm start`.
Без `DATABASE_URL` результаты записываются в файл `data/results.json`.
